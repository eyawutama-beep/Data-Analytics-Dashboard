# Sales Performance Dashboard With – Microsoft Excel

## Project Overview

Turning raw data into meaningful business insights is one of the skills I'm developing as I grow in Data Analytics and Business Intelligence.

As part of that journey, I built an interactive **Sales Performance Dashboard using Microsoft Excel**, taking a raw sales dataset through data cleaning, financial analysis, and visualization to create a reporting tool that makes business performance easier to understand.

The dashboard provides a clear view of revenue, profit, costs, and sales performance across products, regions, and salespersons. It also features interactive slicers that allow users to explore the data and answer important business questions.

This project gave me practical experience in using Excel not just for calculations, but as a tool for analysing business performance and supporting data-driven decisions.

## Tools Used

- Microsoft Excel
- Excel formulas
- PivotTables and PivotCharts
- Excel Slicers

The entire project was completed using Microsoft Excel.

## Project Process

I started by importing and understanding the dataset, then carried out data cleaning and quality checks to improve its reliability. There by Creating Data quality Status, and Numerical quality status, rather than deleting duplicates and empty cell which might legit transactions but lost some part of the information.
Also performed Data quality report to check and identify duplicates, missing values and empty cells or uncompleted tracsactions.

Then, I Carried out financial calculations to measure revenue, cost, profit, profit margin, and units sold.

I used PivotTables to summarise the data and analyse performance across different business areas. After that, I built PivotCharts and arranged them into one interactive dashboard.

Finally, I then added slicers for Product, Region, Salesperson, and Category so users could filter the dashboard and explore the results.

## Business Questions Answered

1. What is the overall financial performance of the business?
2. How does revenue change from month to month?
3. Which region generates the highest revenue?
4. Which products contribute most to revenue?
5. How do revenue and profit compare across salespersons?
6. How does performance change when we filter by product, region, salesperson, or category?

## Key Insights

- The business generated approximately **$19.7 million in revenue** and **$4.96 million in profit**.
- The overall profit margin was **25.20%**.
- The West region recorded the highest revenue among the four regions.
- Monthly revenue varied throughout the year, showing different sales patterns. The month February generated the highest Revenue.
- Product and salesperson performance differed, making comparisons useful for identifying stronger contributors.
